## JMeter 简介

Apache JMeter 是一款 100% 纯 Java 的开源桌面应用程序，设计用于：
- **负载测试**：模拟多用户并发访问，测试服务器的整体性能
- **功能测试**：验证应用程序的正确性
- **性能测量**：测量静态和动态资源的性能

### 核心特性

| 特性 | 说明 |
|------|------|
| **协议支持** | HTTP/HTTPS、SOAP/REST、FTP、JDBC、LDAP、JMS、SMTP/POP3/IMAP、TCP 等 |
| **IDE 集成** | 完整的测试 IDE，支持快速录制、构建和调试 |
| **命令行模式** | CLI 模式可从任何 Java 兼容 OS 加载和运行测试 |
| **HTML 报告** | 完整的动态 HTML 报告，可离线查看 |
| **多线程** | 支持多线程并发采样，不同线程组独立采样 |
| **可扩展性** | 插件化架构，支持自定义采样器、函数等 |
| **脚本支持** | 支持 Groovy、BeanShell、Jexl3 等脚本语言 |

### 版本信息

- **文档版本**：5.6.3
- **Java 要求**：Java 8 及以上
- **操作系统**：任何支持 Java 的操作系统（Windows、Linux、macOS）
