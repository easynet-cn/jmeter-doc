# 03 - 数据库测试计划

## 6. 构建数据库测试计划

### 6.1 添加用户（线程组）

1. 右键点击 Test Plan → **Add → Threads (Users) → Thread Group**
2. 设置线程组属性：
   - **Number of Threads**：`10`
   - **Ramp-Up Period**：`10`
   - **Loop Count**：`100`

---

### 6.2 配置 JDBC 连接

在发送 JDBC 请求之前，需要配置数据库连接。

1. 右键点击 Thread Group → **Add → Config Element → JDBC Connection Configuration**
2. 配置以下参数：

#### JDBC Connection Configuration 参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **Variable Name** | 连接池名称（JDBC Request 中引用） | `myPool` |
| **Max Number of Connections** | 最大连接数 | `10` |
| **Max Wait (ms)** | 等待连接的最长时间 | `10000` |
| **Time Between Eviction Runs (ms)** | 空闲连接检查间隔 | `60000` |
| **Auto Commit** | 自动提交 | `true` |
| **Transaction Isolation** | 事务隔离级别 | `DEFAULT` |
| **Validation Query** | 连接验证查询 | `SELECT 1` |

#### 数据库连接 URL 格式

| 数据库 | JDBC URL 格式 |
|--------|--------------|
| **MySQL** | `jdbc:mysql://host:port/dbname` |
| **PostgreSQL** | `jdbc:postgresql://host:port/dbname` |
| **Oracle** | `jdbc:oracle:thin:@host:port:SID` |
| **SQL Server** | `jdbc:sqlserver://host:port;databaseName=dbname` |
| **H2** | `jdbc:h2:~/test` |

#### 驱动类名

| 数据库 | Driver Class |
|--------|-------------|
| MySQL | `com.mysql.jdbc.Driver` 或 `com.mysql.cj.jdbc.Driver` |
| PostgreSQL | `org.postgresql.Driver` |
| Oracle | `oracle.jdbc.driver.OracleDriver` |
| SQL Server | `com.microsoft.sqlserver.jdbc.SQLServerDriver` |

---

### 6.3 添加 JDBC 请求

1. 右键点击 Thread Group → **Add → Sampler → JDBC Request**
2. 配置：

| 参数 | 说明 |
|------|------|
| **Variable Name** | 引用 JDBC Connection Configuration 中定义的连接池名 |
| **Query Type** | SQL 查询类型 |
| **SQL Query** | SQL 语句 |

#### Query Type 说明

| 类型 | 用途 |
|------|------|
| **Select Statement** | 查询数据 |
| **Update Statement** | 插入/更新/删除数据 |
| **Callable Statement** | 调用存储过程 |
| **Prepared Select Statement** | 参数化查询 |
| **Prepared Update Statement** | 参数化更新 |
| **Commit** | 提交事务 |
| **Rollback** | 回滚事务 |
| **AutoCommit(false)** | 关闭自动提交 |
| **AutoCommit(true)** | 开启自动提交 |

#### SQL 查询示例

**Select 查询**：
```sql
SELECT id, name, email FROM users WHERE status = 'active'
```

**参数化查询**：
```sql
SELECT * FROM users WHERE id = ?
```
参数值：`${userId}`

**Update 查询**：
```sql
INSERT INTO logs (user_id, action, timestamp) VALUES (?, ?, NOW())
```
参数值：`${userId}`, `login`

#### 处理查询结果

JDBC Request 执行后，结果存储在变量中：

| 变量 | 说明 |
|------|------|
| `resultSetName_#` | 结果集行数 |
| `resultSetName_1` | 第一行（列值逗号分隔） |
| `resultSetName_2` | 第二行 |
| `resultSetName_1_colName` | 第一行指定列的值 |

> 变量名 `resultSetName` 由 JDBC Request 的 **Result variable name** 属性指定。

---

### 6.4 添加监听器

添加合适的监听器查看数据库测试结果：

- **View Results Tree**：查看每个请求的详细响应
- **Aggregate Report**：查看聚合统计信息
- **Assertion Results**：查看断言结果
