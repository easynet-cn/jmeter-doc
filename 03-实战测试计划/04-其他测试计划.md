# 04 - 其他测试计划

## FTP 测试计划

### 7.1 添加用户（线程组）

1. 右键点击 Test Plan → **Add → Threads (Users) → Thread Group**
2. 配置线程数和循环次数

### 7.2 添加 FTP 请求默认值

1. 右键点击 Thread Group → **Add → Config Element → FTP Request Defaults**
2. 配置：
   - **Server Name or IP**：FTP 服务器地址
   - **Port**：FTP 端口（默认 21）
   - **Username**：FTP 用户名
   - **Password**：FTP 密码

### 7.3 添加 FTP 请求

1. 右键点击 Thread Group → **Add → Sampler → FTP Request**
2. 配置：

| 参数 | 说明 |
|------|------|
| **Server Name or IP** | FTP 服务器地址 |
| **Remote File** | 远程文件路径 |
| **Local File** | 本地文件路径 |
| **Action** | `get`（下载）或 `put`（上传） |
| **Use Binary mode** | 二进制模式（默认） |
| **Save File in Response** | 在响应中保存文件内容 |

## LDAP 测试计划

### 8a.1 添加用户

1. 添加 Thread Group，配置线程数

### 8a.2 添加登录配置

1. 右键点击 Thread Group → **Add → Config Element → Login Config Element**
2. 配置 LDAP 认证信息

### 8a.3 添加 LDAP 请求默认值

1. 右键点击 Thread Group → **Add → Config Element → LDAP Request Defaults**
2. 配置：
   - **Servername**：LDAP 服务器地址
   - **Port**：LDAP 端口（默认 389）
   - **Root DN**：基础 DN

### 8a.4 添加 LDAP 请求

LDAP Request 支持的操作：

| 操作 | 说明 |
|------|------|
| **Search** | 搜索目录条目 |
| **Add** | 添加条目 |
| **Modify** | 修改条目 |
| **Delete** | 删除条目 |
| **Compare** | 比较属性值 |

### 8b 扩展 LDAP 测试

LDAP Extended Request 支持全部 8 种 LDAP 操作，包括：
- Search
- Add
- Modify
- Delete
- Compare
- Rename
- Bind
- Unbind

## JMS 测试计划

### JMS Point-to-Point (点对点)

1. 添加 JMS Point-to-Point 采样器
2. 配置：
   - **QueueConnectionFactory**：连接工厂 JNDI 名
   - **JNDI Name Request Queue**：请求队列 JNDI 名
   - **JNDI Name Reply Queue**：回复队列 JNDI 名
   - **Communication Style**：`Request Only` 或 `Request Response`
   - **JMS Properties**：初始上下文工厂、提供者 URL

### JMS Publisher/Subscriber (发布/订阅)

| 采样器 | 说明 |
|--------|------|
| **JMS Publisher** | 发布消息到 Topic/Queue |
| **JMS Subscriber** | 从 Topic/Queue 订阅消息 |

## WebService 测试计划

使用 HTTP Request 采样器发送 SOAP 请求：

1. 添加 HTTP Request 采样器
2. 设置 Method 为 **POST**
3. 在 **Body Data** 中添加 SOAP envelope：

```xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/">
   <soapenv:Header/>
   <soapenv:Body>
      <!-- 请求体 -->
   </soapenv:Body>
</soapenv:Envelope>
```

4. 添加 **HTTP Header Manager** 设置：
   - `Content-Type: text/xml;charset=UTF-8`
   - `SOAPAction: "urn:actionName"`
