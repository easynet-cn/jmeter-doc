# 02 - 仪表板报告

JMeter Dashboard Generator 从 CSV 结果文件生成包含图形视图的 HTML 报告。

---

## 概述

仪表板生成器是 JMeter 的模块化扩展，默认从 CSV 文件读取样本，生成 HTML 报告。

### 报告包含的指标

| 模块 | 说明 |
|------|------|
| **APDEX 表** | 基于满意/容忍阈值的应用性能指数 |
| **请求摘要图** | 成功和失败请求百分比 |
| **统计表** | 所有指标汇总（含 3 个可配置百分位） |
| **错误表** | 所有错误及其占比 |
| **Top 5 错误** | 按采样器的 Top 5 错误 |

### 可缩放图表

- 响应时间随时间变化
- 响应时间百分位数随时间变化
- 活动线程数随时间变化
- 字节吞吐量随时间变化
- 延迟/连接时间随时间变化
- 每秒点击量/响应代码/事务数
- 响应时间 vs 每秒请求数
- 响应时间概览/分布

## 前置条件

### 必须保存的 CSV 字段

```properties
jmeter.save.saveservice.bytes = true
jmeter.save.saveservice.label = true
jmeter.save.saveservice.latency = true
jmeter.save.saveservice.response_code = true
jmeter.save.saveservice.response_message = true
jmeter.save.saveservice.successful = true
jmeter.save.saveservice.thread_counts = true
jmeter.save.saveservice.thread_name = true
jmeter.save.saveservice.time = true
jmeter.save.saveservice.connect_time = true
jmeter.save.saveservice.assertion_results_failure_message = true
jmeter.save.saveservice.timestamp_format = ms
```

### Transaction Controller 配置

- 取消勾选 **Generate parent sample**
- 右键节点 → **Apply Naming Policy**

## 生成报告

### 方式 1：负载测试后自动生成

```bash
jmeter -n -t test.jmx -l results.jtl -e -o /path/to/output
```

| 参数 | 说明 |
|------|------|
| `-n` | CLI 模式 |
| `-t` | 测试文件 |
| `-l` | 结果文件 |
| `-e` | 测试后生成报告 |
| `-o` | 输出目录（必须为空或不存在） |

### 方式 2：从已有 CSV 文件生成

```bash
jmeter -g results.jtl -o /path/to/output
```

### 方式 3：GUI 菜单生成

**Tools → Generate HTML report**

| 参数 | 说明 |
|------|------|
| Results file (csv or jtl) | 测试结果 CSV |
| user.properties file | 运行时的属性文件 |
| Output directory | 输出目录 |

## 配置

### 通用设置

所有属性以 `jmeter.reportgenerator.` 为前缀，在 `user.properties` 中配置：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `report_title` | 报告标题 | `Apache JMeter Dashboard` |
| `date_format` | 日期格式 | `yyyyMMddHHmmss` |
| `start_date` | 数据范围开始 | — |
| `end_date` | 数据范围结束 | — |
| `overall_granularity` | 时间粒度（毫秒） | `60000` |
| `apdex_satisfied_threshold` | APDEX 满意阈值（毫秒） | `500` |
| `apdex_tolerated_threshold` | APDEX 容忍阈值（毫秒） | `1500` |
| `sample_filter` | 样本过滤正则 | — |
| `statistic_window` | 百分位滑动窗口 | `20000` |

### 系列过滤

```properties
jmeter.reportgenerator.exporter.html.series_filter=^(Search|Order)(-success|-failure)?$
```

## 自定义图表

图表 ID 以 `custom_` 为前缀：

```properties
jmeter.reportgenerator.graph.custom_myChart.classname=org.apache.jmeter.report.processor.graph.impl.CustomGraphConsumer
jmeter.reportgenerator.graph.custom_myChart.property.set_X_Axis=Time (ms)
jmeter.reportgenerator.graph.custom_myChart.property.set_Y_Axis=My Metric
jmeter.reportgenerator.graph.custom_myChart.property.set_Content_Message=My custom data
jmeter.reportgenerator.graph.custom_myChart.property.set_Sample_Variable_Name=myColumn
```

## APDEX 说明

APDEX（Application Performance Index）是应用性能的标准化度量：

| 等级 | 阈值 | 说明 |
|------|------|------|
| **Satisfied（满意）** | ≤ 满意阈值 | 响应时间满意 |
| **Tolerating（容忍）** | > 满意阈值 且 ≤ 容忍阈值 | 响应时间可容忍 |
| **Frustrated（不满）** | > 容忍阈值 | 响应时间不可接受 |

APDEX 分数范围 0-1，越高越好。
