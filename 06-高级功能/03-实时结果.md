# 03 - 实时结果

自 JMeter 2.13 起，可通过 **Backend Listener** 将实时测试结果发送到后端系统。

---

## 支持的后端

| 后端 | 引入版本 | 协议 | 说明 |
|------|----------|------|------|
| **GraphiteBackendListenerClient** | 2.13 | 文本/Pickle | 发送指标到 Graphite |
| **InfluxDBBackendListenerClient** | 3.2 | UDP 或 HTTP | 发送指标到 InfluxDB |

---

## 暴露的指标

### 线程/虚拟用户

| 指标 | 说明 |
|------|------|
| `<prefix>test.minAT` | 最小活跃线程数 |
| `<prefix>test.maxAT` | 最大活跃线程数 |
| `<prefix>test.meanAT` | 平均活跃线程数 |
| `<prefix>test.startedT` | 已启动线程数 |
| `<prefix>test.endedT` | 已完成线程数 |

### 响应时间

| 指标格式 | 说明 |
|----------|------|
| `<samplerName>.ok.count` | 成功响应数 |
| `<samplerName>.ko.count` | 失败响应数 |
| `<samplerName>.a.count` | 总响应数 |
| `<samplerName>.ok.min/max/avg` | 成功响应时间统计 |
| `<samplerName>.ko.min/max/avg` | 失败响应时间统计 |
| `<samplerName>.ok.pct<值>` | 成功响应百分位 |
| `<samplerName>.h.count` | 每秒点击数 |
| `<samplerName>.sb.bytes` | 发送字节数 |
| `<samplerName>.rb.bytes` | 接收字节数 |

## InfluxDB 配置

### InfluxDB 2.x

需要配置：
- **influxdbToken**：认证令牌
- **bucket** 和 **org**：通过 URL 参数传递

在 InfluxDB UI 中创建 `jmeter` bucket。

### InfluxDB 1.x

```bash
# 创建数据库
curl -i -XPOST http://localhost:8086/query \
  --data-urlencode "q=CREATE DATABASE jmeter"
```

### JMeter Backend Listener 配置

添加 Backend Listener 到测试计划，选择 `InfluxDBBackendListenerClient`：

| 参数 | 说明 | 示例 |
|------|------|------|
| `influxdbMetricsSender` | 发送器类 | `org.apache.jmeter.visualizers.backend.influxdb.HttpMetricsSender` |
| `influxdbUrl` | InfluxDB URL | `http://localhost:8086/api/v2/write?org=myorg&bucket=jmeter` |
| `application` | 应用名 | `myapp` |
| `measurement` | 测量名 | `jmeter` |
| `summaryOnly` | 仅发送汇总 | `false` |
| `samplersRegex` | 采样器过滤正则 | `.*` |
| `percentiles` | 百分位 | `90;95;99` |
| `testTitle` | 测试标题 | `Load Test 2024` |

## Graphite 配置

添加 Backend Listener，选择 `GraphiteBackendListenerClient`：

| 参数 | 说明 |
|------|------|
| `graphiteMetricsSender` | 发送器：`TextGraphiteMetricsSender` 或 `PickleGraphiteMetricsSender` |
| `graphiteHost` | Graphite 主机 |
| `graphitePort` | Graphite 端口（默认 2003） |
| `rootMetricsPrefix` | 指标前缀 |
| `summaryOnly` | 仅发送汇总 |
| `samplersRegex` | 采样器过滤 |
| `percentiles` | 百分位 |

> Pickle 协议比文本协议更高效，适合大数据量。

## Grafana 配置

### 步骤

1. 安装 Grafana
2. 添加 InfluxDB 或 Graphite 数据源
3. 导入仪表盘模板（可从 Grafana 社区获取 JMeter 模板）
4. 配置刷新间隔

### 推荐的 Grafana 面板

| 面板 | 说明 |
|------|------|
| 活跃线程数 | 折线图 |
| 响应时间 | 折线图 + 百分位 |
| 吞吐量 | 折线图 |
| 错误率 | 折线图 / 仪表盘 |
| 网络字节 | 面积图 |

---
