# 03 - 属性与变量

## 3.11 属性与变量 (Properties and Variables)

JMeter 中有两种重要的值存储机制：**属性 (Properties)** 和 **变量 (Variables)**。

### 对比总览

| 特性 | JMeter 属性 (Properties) | JMeter 变量 (Variables) |
|------|--------------------------|--------------------------|
| **定义位置** | `jmeter.properties` 文件 | 测试计划中定义 |
| **作用域** | **全局**，整个 JMeter 实例 | **线程本地**，每个线程独立 |
| **用途** | 定义 JMeter 默认值（如 `remote_hosts`） | 线程特定值 |
| **更新影响** | 全局影响 | 仅影响当前线程的副本 |
| **引用方式** | `__P()` 或 `__property()` 函数 | `${变量名}` |
| **线程间共享** | ✅ 可通过 `setProperty` 函数传递 | ❌ 各线程独立 |
| **生命周期** | JMeter 实例生命周期 | 线程生命周期 |

> 🔤 变量和属性都**区分大小写**。

---

## 属性 (Properties)

### 设置属性

**通过文件**：
```properties
# user.properties 或 jmeter.properties
remote_hosts=127.0.0.1,192.168.1.100
```

**通过命令行**：
```bash
jmeter -Jremote_hosts=127.0.0.1 -Jthreads=100
```

**通过函数**：
```
${__setProperty(myProperty,myValue)}
```

### 读取属性

```
${__P(remote_hosts)}           # 读取属性
${__P(threads,10)}             # 读取属性，带默认值
${__property(remote_hosts)}    # 读取属性（另一种写法）
```

### 常用内置属性

| 属性 | 说明 |
|------|------|
| `START.MS` | 测试开始时间（毫秒） |
| `START.YMD` | 测试开始日期 (yyyyMMdd) |
| `START.HMS` | 测试开始时间 (HHmmss) |
| `TESTSTART.MS` | 测试开始时间戳 |

---

## 变量 (Variables)

### 定义方式

**User Defined Variables 配置元素**：
```
HOST    = www.example.com
PORT    = 8080
THREADS = 10
```

**通过提取器创建**：
- Regular Expression Extractor
- JSON Extractor
- CSS Selector Extractor
- Boundary Extractor

### 引用方式

```
${HOST}
${PORT}
${__V(variableName)}
```

### 线程隔离

每个线程都有自己的变量副本，修改一个线程的变量不会影响其他线程。

---

## 线程间共享数据

### 场景 1：测试前可确定的值

使用参数化测试模式：

```
LOOPS = ${__P(loops,20)}
```

命令行覆盖：
```bash
jmeter -n -t test.jmx -Jloops=100
```

### 场景 2：运行时需要共享的值

| 方法 | 说明 |
|------|------|
| **存储为属性** | 使用 `setProperty()` 函数 |
| **写入文件** | 写入文件后重新读取 |
| **bsh.shared** | BeanShell 共享命名空间 |
| **自定义 Java 类** | 编写自定义共享机制 |

### 属性共享示例

```bash
# 线程 1：设置属性
${__setProperty(token,${extractedToken})}

# 线程 2：读取属性
${__P(token)}
```

## 参数化测试最佳实践

### 使用 CSV 数据集

```
CSV Data Set Config:
  文件：users.csv
  变量：USER,PASS
  分隔符：,
```

在请求中引用：
```
${USER}
${PASS}
```

### 命令行参数化

```bash
# 测试计划中定义
HOST = ${__P(host,localhost)}
PORT = ${__P(port,8080)}

# 命令行运行
jmeter -n -t test.jmx -Jhost=production.example.com -Jport=443
```
