# 01 - 概述与安装

## 1.0 概述

Apache JMeter 是一款 100% 纯 Java 的开源应用程序，旨在加载测试功能行为并测量性能。它最初设计用于测试 Web 应用程序，但后来扩展到其他测试功能。

---

## 1.1 系统要求

### 1.1.1 Java 版本

- JMeter **兼容 Java 8 及以上版本**
- **强烈建议**安装你所使用 Java 主版本的最新次要版本，以确保安全性和性能
- 虽然可以使用 JRE，但最好安装 **JDK**，因为 JMeter 需要 `keytool` 工具来录制 HTTPS 流量

### 1.1.2 操作系统

JMeter 是 100% Java 应用程序，可在任何具有兼容 Java 实现的系统上正确运行。已验证的平台包括：

| 操作系统 | 说明 |
|----------|------|
| Linux/Unix | 完全支持 |
| Windows | 完全支持 |
| macOS | 完全支持 |

---

## 1.2 可选组件

### 1.2.1 Java 编译器

如果需要构建自定义测试插件或修改源代码，需要安装 JDK（而非 JRE）。

### 1.2.2 SAX XML 解析器

JMeter 自带 Apache Xerces XML 解析器，无需额外安装。

### 1.2.3 邮件支持

要使用 Mail Reader Sampler 或 SMTP Sampler，需要：
- `activation.jar`（Java Activation Framework）
- `mail.jar`（JavaMail API）

将这些 jar 文件放入 `lib/` 目录。

### 1.2.4 SSL 加密

JMeter 内置支持 SSL/TLS，默认协议为 TLS。可通过 `system.properties` 配置。

### 1.2.5 JDBC 驱动

要执行数据库测试，需要将相应的 JDBC 驱动 jar 文件放入 `lib/` 目录。支持的数据库包括但不限于：

| 数据库 | 驱动说明 |
|--------|----------|
| MySQL | 需要 `mysql-connector-java.jar` |
| PostgreSQL | 需要 `postgresql.jar` |
| Oracle | 需要 `ojdbc.jar` |
| MS SQL Server | 需要 `mssql-jdbc.jar` |

### 1.2.6 JMS 客户端

JMeter 包含 JMS API 的 jar 文件，但需要提供相应的 JMS 客户端实现 jar。

### 1.2.7 ActiveMQ JMS 库

如需使用 ActiveMQ，将 `activemq-all.jar` 放入 `lib/` 目录。

---

## 1.3 安装

JMeter 的安装非常简单——只需将 zip/tar 文件解压到目标目录即可。

### 目录结构

```
apache-jmeter-X.Y/
├── bin/                    # 启动脚本和属性文件
│   ├── jmeter.bat          # Windows 启动脚本
│   ├── jmeter.sh           # Linux/Unix 启动脚本
│   ├── jmeter.properties   # 主配置文件
│   └── user.properties     # 用户自定义配置
├── docs/                   # 文档目录
├── extras/                 # 额外工具和扩展
├── lib/                    # 核心库
│   ├── ext/                # JMeter 插件和组件
│   └── junit/              # JUnit 测试支持
├── licenses/               # 许可证文件
└── printable_docs/         # 可打印文档
```

### 重要注意事项

1. **不要更改**任何子目录名称（可以重命名父目录）
2. **避免**在目录路径中使用空格（可能导致客户端-服务器模式出现问题）
3. 确保设置了 **`JAVA_HOME`** 环境变量

### 环境变量设置

**Windows（在 `bin/setenv.bat` 中设置）**：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `HEAP` | JVM 内存设置 | `-Xms1g -Xmx1g -XX:MaxMetaspaceSize=256m` |
| `GC_ALGO` | 垃圾回收器选项 | G1GC |
| `JVM_ARGS` | 其他 Java 选项 | — |

**Unix/Linux（在 `bin/setenv.sh` 中设置）**：

| 变量 | 说明 |
|------|------|
| `JAVA_HOME` | Java 安装路径 |
| `JRE_HOME` | JRE 安装路径 |
| `JMETER_HOME` | JMeter 安装路径 |
| `HEAP` | JVM 内存设置 |
| `GC_ALGO` | 垃圾回收器选项 |
| `JVM_ARGS` | 其他 Java 选项 |
