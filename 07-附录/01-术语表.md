# 01 - 术语表

## 核心术语

### Elapsed Time（耗时）
从发送请求前到收到最后一个响应后的总时间。JMeter **不包含**渲染响应或处理客户端 JavaScript 的时间。

### Latency（延迟）
从发送请求前到收到第一个响应字节的时间。包括组装请求的时间。

### Connect Time（连接时间）
建立连接的时间，包括 SSL 握手。连接错误时反映的是错误发生前的时间。

> 自 JMeter 3.1 起，连接时间仅对 TCP Sampler、HTTP Request 和 JDBC Request 计算。

### Median（中位数）
将样本分成两半的数值，即第 50 百分位。一半样本比它小，一半比它大。

### 90% Line（90 百分位）
90% 的样本低于此值，剩余 10% 的样本至少与此值一样高。

### Standard Deviation（标准差）
数据变异性的度量。JMeter 计算的是**总体标准差**（population standard deviation），而非样本标准差。

### Throughput（吞吐量）
单位时间内的请求数。计算公式：`Throughput = 请求数 / 总时间`。总时间从第一个样本开始到最后一个样本结束，包含样本之间的间隔。

### Thread Name（线程名）
监听器和日志文件中显示的线程名称。格式：`groupName + " " + groupIndex + "-" + threadIndex`

**示例**：两个 Thread Group，每个 2 个线程：

| 线程 | 名称 |
|------|------|
| Thread Group 1, Thread 1 | `Thread Group 1-1` |
| Thread Group 1, Thread 2 | `Thread Group 1-2` |
| Thread Group 2, Thread 1 | `Thread Group 2-1` |
| Thread Group 2, Thread 2 | `Thread Group 2-2` |

## 测试计划相关

### Thread Group（线程组）
模拟一组用户执行测试计划的组件。定义线程数、Ramp-Up 周期和循环次数。

### Sampler（采样器）
向服务器发送特定类型请求的组件（HTTP、FTP、JDBC 等）。

### Listener（监听器）
收集和展示测试结果的组件。所有监听器保存相同数据，仅在展示方式上不同。

### Assertion（断言）
验证服务器响应是否符合预期的组件。

### Timer（定时器）
在请求之间引入延迟的组件，模拟真实用户行为。

### Configuration Element（配置元素）
设置默认值和变量的组件，由采样器和其他组件使用。

### Pre-Processor（前置处理器）
在采样器请求之前执行操作的组件。

### Post-Processor（后置处理器）
在采样器请求之后执行操作的组件，常用于提取数据。

### Logic Controller（逻辑控制器）
控制采样器执行顺序和方式的组件。

### Test Fragment（测试片段）
可被 Module Controller 或 Include Controller 引用的可复用测试模块。

---

## 分布式测试

### Client（客户端）
控制远程测试执行的 JMeter 实例，通常为 GUI 或 CLI 模式。

### Server / Engine（服务器/引擎）
运行在远程机器上的 JMeter 实例（`jmeter-server`），接收客户端指令并执行测试。

### RMI（远程方法调用）
Java 远程通信协议，JMeter 用于客户端-服务器通信。

---

## 性能指标

### APDEX（应用性能指数）
应用性能的标准化度量，范围 0-1：
- **Satisfied（满意）**：响应时间 ≤ 满意阈值
- **Tolerating（容忍）**：满意阈值 < 响应时间 ≤ 容忍阈值
- **Frustrated（不满）**：响应时间 > 容忍阈值

### Percentile（百分位）
表示某百分比样本低于此值。例如 95% Line = 500ms 表示 95% 的请求在 500ms 内完成。

---

## 属性与变量

### JMeter Property（属性）
全局范围的配置值，定义在 `jmeter.properties` 中，整个 JMeter 实例共享。

### JMeter Variable（变量）
线程本地值，在测试计划中定义或通过提取器生成，每个线程独立。

### User Defined Variable（用户定义变量）
在测试计划中预定义的变量，在测试开始时初始化。
