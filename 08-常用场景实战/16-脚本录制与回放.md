# 16-脚本录制与回放 🎬

> **难度：★★★☆☆** | HTTP(S) Test Script Recorder + Recording Controller 组合

---

## 1. 场景概述

### 什么是脚本录制？

通过 JMeter 的 **HTTP(S) Test Script Recorder**（代理服务器）拦截浏览器/App 发出的 HTTP 请求，自动生成 JMeter 测试脚本。

### 适用场景

- **快速原型**：快速录下用户操作流程，生成初步测试计划
- **接口发现**：自动捕获前端发起的全部 HTTP 请求
- **补全遗漏**：手动编写脚本后，通过录制检查遗漏的接口
- **复杂流程**：涉及多个页面跳转、AJAX 请求的复杂业务流程

### 录制 vs 手写

| 维度 | 录制 | 手写 |
|------|------|------|
| **速度** | 快，几分钟完成 | 慢，需逐个配置 |
| **准确性** | 可能包含冗余请求 | 精确可控 |
| **可维护性** | 需要清理和重构 | 结构清晰 |
| **参数化** | 需要手动替换 | 天然支持 |
| **适用** | 快速原型、接口发现 | 生产级测试脚本 |

## 2. HTTP(S) Test Script Recorder 配置

### 2.1 添加录制器

```
Test Plan
├── HTTP Request Defaults (可选，设置全局默认值)
├── HTTP Cookie Manager (自动管理 Cookie)
├── Recording Controller (录制请求存放位置)
└── HTTP(S) Test Script Recorder (录制器)
```

**添加方式**：右键 Test Plan → Add → Non-Test Elements → HTTP(S) Test Script Recorder

### 2.2 录制器完整配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **Port** | `8888` | 代理监听端口（避免冲突） |
| **HTTPS Domains** | `*.example.com` | 目标域名（过滤无关请求） |
| **HTTP Sampler settings** | | |
| ├─ Type | `HTTPClient4` | HTTP 客户端实现 |
| ├─ Follow Redirects | ✅ | 自动跟随重定向 |
| ├─ Use KeepAlive | ✅ | 连接复用 |
| └─ Download embedded resources | ☐ | 录制时不自动下载（后续可配置） |
| **Content-Type filter** | | |
| ├─ Include | `text/html.*`, `application/json.*`, `application/xml.*` | 仅录制这些类型 |
| └─ Exclude | `image/.*`, `font/.*`, `text/css.*` | 排除静态资源 |
| **URL Patterns to Include** | `.*\.example\.com.*` | 仅录制匹配的 URL |
| **URL Patterns to Exclude** | `.*\.(png\|jpg\|gif\|css\|js\|ico\|woff).*` | 排除静态资源 |

### 2.3 录制模式

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **Transaction Controller** | 每个页面请求归入一个事务 | 按页面组织脚本 |
| **Simple Controller** | 简单分组 | 基础录制 |
| **Recording Controller** | 全部放入录制控制器 | 便于统一管理 |

> 推荐使用 **Recording Controller**，后续再手动重组为 Transaction Controller。

## 3. 录制步骤

### 3.1 浏览器代理配置

**Chrome / Edge**：

1. 设置 → 系统 → 打开计算机的代理设置
2. 手动代理：`127.0.0.1:8888`
3. 或使用 SwitchyOmega 插件快速切换

**Firefox**：

1. 设置 → 网络设置 → 手动代理配置
2. HTTP 代理：`127.0.0.1`，端口：`8888`
3. 勾选"也将此代理用于 HTTPS"

### 3.2 HTTPS 录制（安装证书）

录制 HTTPS 请求需要安装 JMeter 的自签名证书：

1. **启动录制器**：点击 HTTP(S) Test Script Recorder 的 `Start` 按钮
2. **生成证书**：JMeter 会在 `bin/` 目录生成 `ApacheJMeterTemporaryRootCA.crt`
3. **安装证书**：
   - **macOS**：双击 `.crt` → 钥匙串 → 系统 → 始终信任
   - **Windows**：双击安装 → 受信任的根证书颁发机构
   - **Firefox**：单独在 Firefox 证书管理器中导入
4. **重启浏览器**

### 3.3 开始录制

```
1. 启动 JMeter 录制器 (Start)
2. 配置浏览器代理
3. 在浏览器中操作目标网站
4. 操作完成后停止录制器 (Stop)
5. 检查生成的 HTTP Request Samplers
```

### 3.4 录制后清理

```
录制完成后需要手动处理：
├── 删除无关请求（静态资源、第三方统计、埋点）
├── 合并重复请求（参数化）
├── 添加 CSV Data Set Config（替换硬编码数据）
├── 添加提取器（正则/JSON Extractor 替换动态值）
├── 添加断言
├── 添加 Think Time（Constant Timer）
└── 重组测试计划结构
```

## 4. 录制优化技巧

### 4.1 过滤静态资源

在录制器 URL Patterns to Exclude 中配置：

```
.*\.(png|jpg|jpeg|gif|svg|ico|bmp|webp|css|js|woff|woff2|ttf|eot).*
```

### 4.2 过滤第三方域名

```
URL Patterns to Include: .*\.myapp\.com.*
URL Patterns to Exclude: .*google-analytics.*|.*facebook.*|.*doubleclick.*
```

### 4.3 自动添加 Think Time

```
HTTP(S) Test Script Recorder → 高级设置
├── Create transaction per page: ✅
└── Think Time (ms): 500-2000
```

### 4.4 录制模板

创建录制专用模板（保存为 `recording_template.jmx`）：

```
Test Plan
├── User Defined Variables (环境变量)
├── HTTP Request Defaults
│   ├── Protocol: https
│   ├── Server: ${__P(host,dev.example.com)}
│   └── Port: 443
├── HTTP Cookie Manager
├── HTTP Header Manager (公共 Header)
├── Recording Controller
├── View Results Tree
└── HTTP(S) Test Script Recorder
```

每次录制时打开此模板，无需重复配置。

## 5. 录制后重构

### 5.1 静态值参数化

```diff
# 录制生成的原始请求：
- GET /api/users/12345/orders

# 重构后：
+ GET /api/users/${userId}/orders
```

### 5.2 动态值提取

录制的请求中常包含动态 token/session ID，需要替换为提取器：

```xml
<!-- 录制后添加 JSON Extractor 提取 token -->
<JSONPostProcessor>
  <stringProp name="names">authToken</stringProp>
  <stringProp name="jsonPathExprs">$.data.token</stringProp>
  <stringProp name="matchNumbers">1</stringProp>
  <stringProp name="defaultValues">NOT_FOUND</stringProp>
</JSONPostProcessor>

<!-- 将后续请求中的硬编码 token 替换为 ${authToken} -->
```

### 5.3 模块化重组

```diff
# 录制后的扁平结构：
- Recording Controller
  ├── GET /api/login
  ├── POST /api/login
  ├── GET /api/users/me
  ├── GET /api/orders
  └── GET /api/products

# 重构后的模块化结构：
- Simple Controller (登录模块)
│ ├── GET /api/login
│ └── POST /api/login
├── Simple Controller (用户信息)
│ └── GET /api/users/me
├── Simple Controller (订单查询)
│ └── GET /api/orders
└── Simple Controller (商品浏览)
    └── GET /api/products
```

## 6. 移动端 App 录制

### 6.1 iOS 录制

1. **设置代理**：WiFi → 配置代理 → 手动 → `JMeter_IP:8888`
2. **安装证书**：Safari 访问 `http://JMeter_IP:8888` 下载证书描述文件
3. **信任证书**：设置 → 通用 → 关于本机 → 证书信任设置 → 启用
4. **操作 App**：在 App 中执行测试流程
5. **停止录制并清理**

### 6.2 Android 录制

1. **设置代理**：WiFi → 高级选项 → 手动代理 → `JMeter_IP:8888`
2. **安装证书**：浏览器访问 `http://JMeter_IP:8888` 下载 `.crt`
3. **安装为 CA 证书**：设置 → 安全 → 加密与凭据 → 从存储设备安装
4. **操作 App**：Android 7+ 需要 App 配置 `network_security_config.xml` 信任用户证书

> ⚠️ Android 7+ 默认不信任用户安装的 CA 证书。对于非 debug 包，需要使用 VPN 抓包工具（如 mitmproxy）或修改 App 的网络安全配置。

## 7. 高级录制技术

### 7.1 BlazeMeter Chrome 插件

[BlazeMeter Chrome Extension](https://chrome.google.com/webstore/detail/blazemeter-the-continuous/mbopgmdnpcbohhpnfglgohlbhfongabi) 可以直接在浏览器中录制并导出为 `.jmx` 文件。

**优势**：
- 无需配置代理
- 无需安装证书
- 自动生成 JMX 文件

**劣势**：
- 部分高级配置不支持
- HTTPS 请求可能受限
- 依赖第三方服务

### 7.2 通过 HAR 文件导入

1. 浏览器 DevTools → Network → 操作后右键 → Save all as HAR
2. 使用 JMeter 插件导入 HAR 文件（需要 [HAR Importer Plugin](https://github.com/Blazemeter/har2jmeter)）

### 7.3 Badboy 录制（传统方式）

Badboy 是早期常用的 JMeter 录制工具，现已不再维护，不推荐使用。

## 8. 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **浏览器无法上网** | 代理未启动或端口被占用 | 确认录制器已 Start，换端口 |
| **HTTPS 请求失败/证书错误** | 未安装 JMeter 证书 | 安装并信任 `ApacheJMeterTemporaryRootCA.crt` |
| **录到大量无关请求** | 未配置过滤规则 | 配置 URL Patterns Include/Exclude |
| **静态资源占满脚本** | 未排除静态资源 | 添加 `image/.*`, `font/.*` 等到 Exclude |
| **录制后回放失败** | 动态值已过期 | 添加提取器替换 session/token/csrf |
| **移动端证书不生效** | Android 7+ 限制 | 使用 debug 包或 VPN 抓包方案 |
| **端口 8888 被占用** | 其他代理（如 Fiddler）占用 | 更换端口或关闭其他代理 |
