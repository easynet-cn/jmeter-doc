## 1. 场景概述

### 适用场景

- **邮件发送服务压测**：验证 SMTP 服务器的并发发送能力
- **邮件通知系统**：测试注册邮件、验证码邮件、告警邮件的可靠性
- **邮件接收测试**：通过 IMAP/POP3 验证邮件是否正确到达
- **邮件网关性能**：评估邮件中继/网关的吞吐

### JMeter 邮件测试架构

```
Thread Group (发送)
├── SMTP Sampler (发送邮件)
│   ├── SMTP Server + Port
│   ├── From / To / CC / BCC
│   ├── Subject / Message
│   └── Attachment (可选)
│
Thread Group (接收验证)
├── Mail Reader Sampler (读取邮件)
│   ├── IMAP/POP3 Server + Port
│   ├── Username / Password
│   ├── Folder: INBOX
│   └── Number of messages to fetch
└── JSR223 PostProcessor (解析邮件内容)
```

## 3. Mail Reader Sampler — 邮件读取

### 3.1 基本配置

```
Thread Group (邮件接收验证)
├── Mail Reader Sampler
│   ├── Server Type: imap (或 pop3)
│   ├── Server: imap.example.com
│   ├── Port: 993
│   ├── Username: ${toEmail}
│   ├── Password: ${password}
│   ├── Folder: INBOX
│   ├── Number of messages: 5
│   ├── Fetch headers only: ☐
│   ├── Delete messages: ☐
│   └── Store MIME message: ✅
└── JSR223 PostProcessor (解析邮件)
```

### 3.2 配置详解

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **Server Type** | `imap` | 协议类型：`imap` / `pop3` / `imaps` / `pop3s` |
| **Server** | `imap.example.com` | 邮件服务器 |
| **Port** | `993` | IMAP=993, POP3=995 |
| **Username** | `${toEmail}` | 邮箱账号 |
| **Password** | `${password}` | 邮箱密码/授权码 |
| **Folder** | `INBOX` | 邮箱文件夹 |
| **Number of messages** | `10` | 拉取邮件数量（-1 = 全部） |
| **Fetch headers only** | ☐ | 仅获取邮件头 |
| **Delete messages** | ☐ | 读取后删除（谨慎！） |
| **Store MIME message** | ✅ | 存储完整 MIME 消息 |

### 3.3 邮件内容解析

```groovy
// JSR223 PostProcessor - 解析 Mail Reader 返回的邮件
import javax.mail.internet.MimeMessage;
import javax.mail.Session;
import javax.mail.internet.MimeMultipart;
import java.util.Properties;
import javax.mail.Message;

// Mail Reader 将邮件存入 JMeter 变量
def folderMessages = vars.getObject("msg_1"); // msg_1, msg_2, ...
if (folderMessages instanceof Message[]) {
    def messages = (Message[]) folderMessages;
    
    messages.eachWithIndex { msg, idx ->
        def subject = msg.getSubject();
        def from = msg.getFrom()[0].toString();
        def sentDate = msg.getSentDate();
        
        // 提取正文
        def content = "";
        if (msg.getContent() instanceof MimeMultipart) {
            def multipart = (MimeMultipart) msg.getContent();
            for (int i = 0; i < multipart.getCount(); i++) {
                def part = multipart.getBodyPart(i);
                if (part.getContentType().startsWith("text/plain") ||
                    part.getContentType().startsWith("text/html")) {
                    content += part.getContent().toString();
                }
            }
        } else {
            content = msg.getContent().toString();
        }
        
        // 提取验证码（正则匹配）
        def matcher = (content =~ /验证码.*?(\d{6})/);
        if (matcher.find()) {
            vars.put("verificationCode", matcher.group(1));
            log.info("Found verification code: ${matcher.group(1)}");
        }
        
        vars.put("emailSubject_${idx}", subject);
        vars.put("emailContent_${idx}", content);
    }
}
```

## 4. 端到端邮件验证场景

### 4.1 注册验证码流程测试

```
setUp Thread Group
├── Mail Reader Sampler - 清空收件箱

Thread Group (注册流程)
├── HTTP Request - 发送验证码接口
│   └── POST /api/send-verification-code
├── Constant Timer (3000ms - 等待邮件到达)
├── Mail Reader Sampler - 读取最新邮件
├── JSR223 PostProcessor - 提取验证码
├── HTTP Request - 验证验证码
│   └── POST /api/verify-code  (Body: ${verificationCode})
└── Response Assertion - 验证通过

tearDown Thread Group
├── Mail Reader Sampler - 清理测试邮件
```

### 4.2 发送-接收延时测量

```groovy
// JSR223 PreProcessor - 记录发送时间
def sendTime = System.currentTimeMillis();
vars.put("emailSendTime", sendTime.toString());

// SMTP Sampler 发送邮件...

// JSR223 PostProcessor - 计算端到端延迟
def sendTime = vars.get("emailSendTime") as Long;
def recvTime = System.currentTimeMillis();
def latency = recvTime - sendTime;

vars.put("emailLatency", latency.toString());

if (latency > 10000) {
    log.warn("Email delivery too slow: ${latency}ms");
}
```

## 5. 关键断言

| 断言类型 | 配置 | 用途 |
|----------|------|------|
| **Response Assertion** | Response Code = `250` | SMTP 发送成功（250 OK） |
| **Response Assertion** | Contains: `Message accepted` | 邮件被接受 |
| **Duration Assertion** | < `5000` | 发送超时检测 |
| **JSR223 Assertion** | 验证收件箱有新邮件 | 接收验证 |
| **JSON Assertion** | （SMTP 不适用） | - |

```groovy
// JSR223 Assertion - 验证邮件是否成功到达
def messages = vars.getObject("msg_1");
if (messages == null || messages.length == 0) {
    AssertionResult.setFailure(true);
    AssertionResult.setFailureMessage("No email received");
}
```

## 6. 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **Authentication failed** | 密码错误或需授权码 | 使用邮箱授权码而非登录密码 |
| **Connection refused** | 端口或协议错误 | 确认 SMTP/IMAP/POP3 端口和协议 |
| **javax.mail.NoSuchProviderException** | 缺少 mail 库 | JMeter 自带，确认 `lib/mail-*.jar` 存在 |
| **SSL handshake failed** | 证书问题 | 测试环境可勾选 Trust all certificates |
| **邮件在垃圾箱** | 反垃圾策略 | 添加 SPF/DKIM 记录，降低发送频率 |
| **发送频率限制** | 邮箱服务商限制 | Gmail 500封/天，企业邮箱 200-1000封/小时 |

## 7. 性能优化建议

1. **连接复用**：SMTP 支持连接复用，减少握手开销
2. **异步发送**：使用 `javax.mail` 异步模式
3. **批量发送**：一条 SMTP 连接发送多封邮件
4. **本地 MailHog**：压测环境使用 MailHog/GreenMail 等本地 Mock SMTP
5. **附件大小限制**：大附件会导致 OOM，控制在 10MB 以内
6. **分布式执行**：避免单 IP 触发邮件服务商的频率限制
