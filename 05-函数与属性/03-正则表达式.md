# 03 - 正则表达式

JMeter 默认使用 Apache Jakarta ORO 正则引擎（自 JMeter 5.5 起可切换为 JDK 引擎）。

---

## 切换正则引擎

```properties
# user.properties
jmeter.regex.engine=oro    # 默认，ORO 引擎
# jmeter.regex.engine=jdk  # JDK 引擎
```

---

## 核心概念

### Contains vs Matches

| 概念 | 说明 | 示例 |
|------|------|------|
| **contains** | 正则表达式匹配了目标的**部分** | `ph.b.` 包含在 `alphabet` 中 |
| **matches** | 正则表达式匹配了**整个**目标 | `al.*t` 匹配 `alphabet` |

### 与 Perl 的区别

- **不要**用斜杠 `/ /` 括起正则表达式
- 修饰符使用扩展语法：`(?i)` 代替 `/i`

```
Perl:   /abc/i
JMeter: (?i)abc
```

---

## 修饰符

修饰符从其放置位置开始生效。

| 修饰符 | 说明 |
|--------|------|
| `(?i)` | 大小写不敏感 |
| `(?s)` | 单行模式（`.` 匹配换行符） |
| `(?m)` | 多行模式（`^` `$` 匹配每行首尾） |
| `(?x)` | 忽略空白和注释 |
| `(?-i)` | 关闭大小写不敏感 |

### 部分修饰示例

```
Match ExAct case or (?i)ArBiTrARY(?-i) case
```

匹配 "arbitrary" 或 "ARBitrary"，但不匹配 "exact"。

> ⚠️ ORO Bug：修饰符不能放在正则表达式的最末尾。

---

## 特殊字符（元字符）

需要转义的特殊字符：

| 字符 | 用途 | 转义后 |
|------|------|--------|
| `(` `)` | 分组 | `\\(` `\\)` |
| `[` `]` | 字符类 | `\\[` `\\]` |
| `{` `}` | 重复 | `\\{` `\\}` |
| `*` `+` `?` | 重复 | `\\*` `\\+` `\\?` |
| `.` | 通配符 | `\\.` |
| `\\` | 转义 | `\\\\` |
| `\|` | 或 | `\\|` |
| `^` `$` | 行首尾 | `\\^` `\\$` |

> ⚠️ ORO 不支持 `\Q` 和 `\E` 引用序列，使用 `${__escapeOroRegexpChars(value)}` 函数代替。

## 常用正则模式

### 提取单个值

从 `name="file" value="readme.txt"` 中提取文件名：

```
正则：name="file" value="([^"]+)"
```

> 💡 使用 `[^"]+`（匹配非引号字符）比 `.+?`（非贪婪）更高效。

### 提取多个值

从 `name="file.name" value="readme.txt"` 提取两个值：

```
正则：name="([^"]+)" value="([^"]+)"
模板：$1$ $2$
```

生成的变量（Reference Name = `MYREF`）：

| 变量 | 值 |
|------|---|
| `MYREF` | 模板拼接结果 |
| `MYREF_g0` | 完整匹配 |
| `MYREF_g1` | `file.name` |
| `MYREF_g2` | `readme.txt` |

## Regular Expression Extractor 配置

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| **Apply to** | 应用于 | Main sample only |
| **Field to check** | 检查字段 | Body |
| **Reference Name** | 引用名 | 有意义的名称 |
| **Regular Expression** | 正则表达式 | — |
| **Template** | 模板 | `$1$` |
| **Match No.** | 匹配编号 | `1` |
| **Default Value** | 默认值 | `NOT_FOUND` |

## 实用正则示例

### 提取 HTML 标签内容

```html
<title>Welcome to My Site</title>
```

```
正则：<title>([^<]+)</title>
结果：Welcome to My Site
```

### 提取 JSON 值

```json
{"token": "abc123def456", "userId": 42}
```

```
正则："token":\s*"([^"]+)"
结果：abc123def456
```

### 提取 URL 参数

```
https://example.com/page?id=123&name=test
```

```
正则：id=(\d+)
结果：123
```

### 提取 CSRF Token

```html
<input type="hidden" name="_csrf" value="xyz789" />
```

```
正则：name="_csrf"\s+value="([^"]+)"
结果：xyz789
```

## 测试正则表达式

### 方法 1：View Results Tree

在 View Results Tree 中使用 **RegExp Tester** 面板直接测试。

### 方法 2：独立测试

创建简单测试计划：
1. 添加 HTTP Request 或 Java Request 加载测试数据
2. 添加 Regular Expression Extractor
3. 添加 Debug Sampler 查看提取结果
4. 使用 View Results Tree 验证
