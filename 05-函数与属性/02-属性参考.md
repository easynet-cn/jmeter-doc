# 02 - 属性参考

JMeter 属性控制应用程序行为。建议在 `user.properties` 文件中自定义，不要修改 `jmeter.properties`。

---

## 语言和外观

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `language` | GUI 语言（必须在 `jmeter.properties` 设置） | JVM 默认 |
| `locales.add` | 额外语言列表 | `en,fr,de,no,es,tr,ja,zh_CN,zh_TW,pl,pt_BR` |

---

## SSL/TLS 配置

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `https.default.protocol` | 默认 HTTPS 协议 | `TLS` |
| `https.socket.protocols` | 启用的协议列表 | — |
| `https.cipherSuites` | SSL 密码套件 | JVM 默认 |
| `https.sessioncontext.shared` | 线程间共享 SSL 上下文 | `false` |

---

## 远程测试 / RMI

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `remote_hosts` | 远程主机列表（逗号分隔） | `127.0.0.1` |
| `server_port` | RMI 端口 | `1099` |
| `server.rmi.ssl.disable` | 禁用 RMI SSL | `false` |
| `client.tries` | 初始化重试次数 | `1` |
| `client.retries_delay` | 重试延迟（毫秒） | `5000` |
| `client.continue_on_fail` | 远程失败后继续 | `false` |
| `server.exitaftertest` | 测试后退出服务器 | `true` |

### 远程结果批处理

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `mode` | 批处理模式 | `StrippedBatch` |
| `num_sample_threshold` | 累积样本数 | `100` |
| `time_threshold` | 保留时间（毫秒） | `60000` |

**模式选项**：`Standard`、`Batch`、`Statistical`、`Stripped`、`StrippedBatch`、`Asynch`、`StrippedAsynch`

---

## HTTP 请求配置

### Java HTTP 实现

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `http.java.sampler.retries` | 连接重试次数 | `0` |
| `jmeter.httpsampler` | 默认 HTTP 采样器 | `HttpClient4` |

### HttpClient 通用

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `httpclient.timeout` | 套接字超时（毫秒，0=无） | `0` |
| `httpclient.version` | HTTP 版本 | `1.1` |
| `httpclient.socket.http.cps` | HTTP 慢速连接模拟 | `0` |
| `httpclient.socket.https.cps` | HTTPS 慢速连接模拟 | `0` |

### HttpClient4

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `httpclient4.retrycount` | 重试次数（仅幂等方法） | `0` |
| `httpclient4.idletimeout` | 空闲连接超时 | `0` |
| `httpclient4.time_to_live` | 连接 TTL（毫秒） | `60000` |
| `httpclient4.validate_after_inactivity` | 非活跃后检查间隔 | `4900` |

## 结果文件配置

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `jmeter.save.saveservice.output_format` | 输出格式 | `csv` |
| `jmeter.save.saveservice.response_data` | 保存响应数据 | `false` |
| `jmeter.save.saveservice.response_data.on_error` | 仅保存失败响应数据 | `false` |
| `jmeter.save.saveservice.timestamp_format` | 时间戳格式 | `ms` |
| `jmeter.save.saveservice.assertion_results_failure_message` | 保存断言失败消息 | `true` |
| `sample_variables` | 保存的额外变量 | — |

---

## 报告生成

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `jmeter.reportgenerator.apdex_satisfied_threshold` | APDEX 满意阈值（毫秒） | `500` |
| `jmeter.reportgenerator.apdex_tolerated_threshold` | APDEX 容忍阈值（毫秒） | `1500` |
| `jmeter.reportgenerator.report_title` | 报告标题 | `Apache JMeter Dashboard` |
| `jmeter.reportgenerator.overall_granularity` | 时间粒度（毫秒） | `60000` |
| `jmeter.reportgenerator.sample_filter` | 样本过滤正则 | — |
| `jmeter.reportgenerator.statistic_window` | 百分位滑动窗口 | `20000` |

---

## 聚合报告百分位

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `aggregate_rpt_pct1` | 第一个百分位 | `90` |
| `aggregate_rpt_pct2` | 第二个百分位 | `95` |
| `aggregate_rpt_pct3` | 第三个百分位 | `99` |

---

## Backend Listener

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `backend_graphite.send_interval` | Graphite 发送间隔（秒） | `1` |
| `backend_influxdb.send_interval` | InfluxDB 发送间隔（秒） | `5` |
| `backend_influxdb.connection_timeout` | InfluxDB 连接超时（毫秒） | `1000` |
| `backend_metrics_window` | 百分位滑动窗口 | `100` |

---

## 录制器配置

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `proxy.pause` | 间隔检测阈值（毫秒） | `5000` |
| `proxy.number.requests` | 采样器名添加数字后缀 | `true` |
| `proxy.excludes.suggested` | 建议排除的 URL 模式 | `.*\\.(bmp\|css\|js\|gif\|ico\|jpe?g\|png\|swf\|woff\|woff2)` |

---

## 杂项

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `sampleresult.default.encoding` | 默认编码 | `UTF-8` |
| `httpsampler.max_redirects` | 最大重定向次数 | `20` |
| `view.results.tree.max_results` | 树视图最大样本数 | `500` |
| `jmeter.regex.engine` | 正则引擎 | `oro` |
| `CookieManager.delete_null_cookies` | 删除空 Cookie | `true` |
| `CookieManager.save.cookies` | 保存 Cookie 为变量 | `false` |
| `CookieManager.name.prefix` | Cookie 变量前缀 | `COOKIE_` |

## 定时器

## CSV DataSet

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `csvdataset.eofstring` | 文件结束字符串 | `<EOF>` |

---

## 类路径

| 属性 | 说明 |
|------|------|
| `search_paths` | 额外插件类目录（`;` 分隔） |
| `user.classpath` | 工具/依赖类目录 |
| `plugin_dependency_paths` | 插件依赖目录 |

---

## 属性文件加载顺序

1. `-p propfile` 指定的文件
2. `jmeter.properties`
3. `user.properties`
4. `system.properties`
5. 命令行选项
