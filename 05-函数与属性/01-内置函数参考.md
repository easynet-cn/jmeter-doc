# 01 - 内置函数参考

JMeter 提供 50+ 个内置函数，使用 `${__functionName(param1,param2,...)}` 格式调用。

> ⚠️ 注意：
> - 变量、函数和属性都**区分大小写**
> - 如果参数包含逗号，必须用反斜杠转义：`\,`

---

## 信息类函数

### threadNum
获取线程编号。

```
${__threadNum}
```

### threadGroupName
获取线程组名称。

```
${__threadGroupName}
```

### samplerName
获取采样器名称（标签）。

```
${__samplerName}
```

### machineIP
获取本地机器 IP 地址。

```
${__machineIP}
${__machineIP(name)}       # 指定接口名
```

### machineName
获取本地机器名称。

```
${__machineName}
```

### time
返回当前时间（多种格式）。

```
${__time(YYYY-MM-dd)}       # 日期
${__time(HH:mm:ss)}          # 时间
${__time(YYYY-MM-dd HH:mm:ss)}
${__time(,)}                 # 毫秒时间戳
${__time(/1000,)}            # 秒时间戳
```

### timeShift
返回偏移后的时间。

```
${__timeShift(YYYY-MM-dd HH:mm:ss,,P1D,,)}     # 加 1 天
${__timeShift(,,P-1H,,)}                        # 减 1 小时
${__timeShift(,,PT30M,,)}                       # 加 30 分钟
```

### log / logn
记录日志并返回值。

```
${__log(Hello World)}         # 记录并返回
${__logn(Hello World)}        # 记录但返回空字符串
${__log(Message,OUT)}         # 输出到控制台
${__log(Message,ERR)}         # 输出到错误
${__log(Message,WARN)}        # 警告级别
```

## 输入类函数

### StringFromFile
从文件中逐行读取。

```
${__StringFromFile(data.txt)}
${__StringFromFile(data.txt,,)}              # 自动序列
${__StringFromFile(data.txt,seq1,)}          # 指定序列
```

### FileToString
读取整个文件内容。

```
${__FileToString(data.txt,,)}
${__FileToString(data.json,UTF-8,)}
```

### CSVRead
从 CSV 文件读取。

```
${__CSVRead(data.csv,0)}      # 第一列
${__CSVRead(data.csv,1)}      # 第二列
${__CSVRead(data.csv,next())} # 下一行
```

### XPath
使用 XPath 从文件读取。

```
${__XPath(test.xml,//user/name)}
```

### StringToFile
将字符串写入文件。

```
${__StringToFile(output.txt,${data},,)}
${__StringToFile(output.txt,${data},true,)}   # 追加模式
```

## 计算类函数

### counter
生成递增数字。

```
${__counter(TRUE,)}           # 全局计数
${__counter(FALSE,counter1)}  # 每线程独立
```

### Random
生成随机数。

```
${__Random(0,100,)}           # 0-100
${__Random(1000,9999,randomId)}
```

### RandomDate
生成指定范围内的随机日期。

```
${__RandomDate(2020-01-01,2023-12-31,YYYY-MM-dd,)}
```

### RandomString
生成随机字符串。

```
${__RandomString(10,abcdefghijklmnopqrstuvwxyz,)}
${__RandomString(8,1234567890,)}
```

### RandomFromMultipleVars
从多个变量值中随机选一个。

```
${__RandomFromMultipleVars(var1|var2|var3,)}
```

### UUID
生成随机 UUID（类型 4）。

```
${__UUID}
```

### intSum
整数求和。

```
${__intSum(1,2,3,)}           # 结果 = 6
${__intSum(${a},${b},)}
```

### longSum
长整数求和。

```
${__longSum(1000000000,2000000000,)}
```

### digest
生成摘要（MD5、SHA-1、SHA-256 等）。

```
${__digest(MD5,hello world,,,)}
${__digest(SHA-256,${data},,,)}
${__digest(SHA-1,hello,uppercase,,)}
```

${__dateTimeConvert(01232022,MMddyyyy,yyyy-MM-dd,)}
${__dateTimeConvert(2023-01-15,yyyy-MM-dd,MM/dd/yyyy,)}

## 脚本类函数

### groovy
运行 Groovy 脚本。

```
${__groovy(2 + 2,)}                              # 返回 4
${__groovy(vars.get("count") as int + 1,)}
${__groovy(new Date().format("yyyy-MM-dd"),)}
```

### BeanShell (已弃用)
运行 BeanShell 脚本。

```
${__BeanShell(vars.get("count") + 1,)}
```

> ⚠️ 建议使用 `__groovy` 代替。

### javaScript
运行 JavaScript 脚本。

```
${__javaScript(Math.random() * 100,)}
```

### jexl2 / jexl3
评估 JEXL 表达式。

```
${__jexl3(${count} < 10,)}
${__jexl3("${status}" == "OK",)}
```

## 属性类函数

### property / P
读取 JMeter 属性。

```
${__property(remote_hosts)}          # 读取属性
${__P(threads,10)}                   # 读取属性，带默认值
${__P(host,localhost)}
```

### setProperty
设置 JMeter 属性。

```
${__setProperty(token,${extractedToken},)}
${__setProperty(myVar,value)}
```

### isPropDefined
检查属性是否定义。

```
${__isPropDefined(remote_hosts)}
```

### isVarDefined
检查变量是否定义。

```
${__isVarDefined(userName)}
```

## 变量类函数

### split
分割字符串为变量。

```
${__split(apple,banana,orange,fruits,,)}
# 生成: fruits_1=apple, fruits_2=banana, fruits_3=orange, fruits_n=3
```

### eval
评估变量表达式。

```
${__eval(${varName})}
${__eval(${expression})}
```

### evalVar
评估存储在变量中的表达式。

```
${__evalVar(expressionVar)}
```

### V
评估变量名（嵌套变量引用）。

```
${__V(user${__counter(FALSE,)})}
# 解析为 user1, user2, user3...
```

## 字符串类函数

### changeCase
改变大小写。

```
${__changeCase(hello world,UPPER,)}        # HELLO WORLD
${__changeCase(HELLO,LOWER,)}              # hello
${__changeCase(hello world,CAPITALIZE,)}   # Hello World
```

### escapeHtml / unescapeHtml
HTML 编解码。

```
${__escapeHtml(<div>Hello</div>)}
${__unescapeHtml(&lt;div&gt;Hello&lt;/div&gt;)}
```

### escapeXml
XML 编码。

```
${__escapeXml(<name>Tom & Jerry</name>)}
```

### escapeOroRegexpChars
转义 ORO 正则表达式特殊字符。

```
${__escapeOroRegexpChars(a.b*c?d)}
```

### urlencode / urldecode
URL 编解码。

```
${__urlencode(hello world)}           # hello+world
${__urldecode(hello%20world)}         # hello world
```

### regexFunction
使用正则表达式解析响应。

```
${__regexFunction(responseData,(\\d+),$1$,)}
```

### unescape
处理 Java 转义字符。

```
${__unescape(Hello\\nWorld)}
```

### char
生成 Unicode 字符。

```
${__char(65,66,67)}       # ABC
${__char(20013,22269)}    # 中国
```

### TestPlanName
返回当前测试计划名称。

```
${__TestPlanName}
```
