# 01 - 采样器 (Samplers)

采样器是 JMeter 的核心组件，负责向服务器发送请求并等待响应。

---

## HTTP Request

发送 HTTP/HTTPS 请求，是 JMeter 中最常用的采样器。

### 基本配置

| 参数 | 说明 |
|------|------|
| **Protocol** | `http` 或 `https` |
| **Server Name or IP** | 目标服务器地址 |
| **Port Number** | 端口号 |
| **Method** | GET、POST、PUT、DELETE、HEAD、OPTIONS、PATCH |
| **Path** | 请求路径（如 `/api/users`） |

### 高级选项

| 选项 | 说明 |
|------|------|
| **Redirect Automatically** | 自动跟随重定向 |
| **Follow Redirects** | 跟随重定向（不自动） |
| **Use KeepAlive** | 使用持久连接 |
| **Use multipart/form-data** | POST 文件上传 |
| **Browser-compatible headers** | 模拟浏览器请求头 |

### GraphQL HTTP Request

专门的 GraphQL 查询界面，提供更便捷的 GraphQL 请求配置。

---

## FTP Request

发送 FTP 文件上传/下载请求。

| 参数 | 说明 |
|------|------|
| **Remote File** | 远程文件路径 |
| **Local File** | 本地文件路径 |
| **Action** | `get(RETR)` 下载 / `put(STOR)` 上传 |
| **Use Binary mode** | 二进制传输模式 |

---

## JDBC Request

发送数据库 SQL 查询。

| 参数 | 说明 |
|------|------|
| **Variable Name** | 连接池名（引用 JDBC Connection Configuration） |
| **Query Type** | Select / Update / Callable / Prepared Select / Prepared Update / Commit / Rollback |
| **SQL Query** | SQL 语句，支持 `?` 参数占位符 |
| **Parameter values** | 逗号分隔的参数值 |
| **Parameter types** | 逗号分隔的参数类型 |
| **Result variable name** | 结果存储变量名 |

---

## Java Request

执行自定义 Java 类实现的采样器。

| 参数 | 说明 |
|------|------|
| **Classname** | 实现 `JavaSamplerClient` 接口的类名 |
| **Parameters** | 传递给 Java 类的参数 |

---

## JUnit Request

在 JMeter 中运行 JUnit 测试类。

| 参数 | 说明 |
|------|------|
| **Classname** | 包含 JUnit 测试的类名 |
| **Test Method** | 指定测试方法 |
| **Append Error** | 错误处理方式 |
| **Append Exception** | 异常处理方式 |

---

## LDAP Request / LDAP Extended Request

发送 LDAP 目录服务请求。

### LDAP Request 支持的操作

| 操作 | 说明 |
|------|------|
| Add | 添加条目 |
| Modify | 修改条目 |
| Delete | 删除条目 |
| Search | 搜索条目 |
| Compare | 比较属性值 |

### LDAP Extended Request

额外支持：Rename、Bind、Unbind

## Access Log Sampler

读取 Web 服务器访问日志，基于日志内容生成 HTTP 请求。

| 参数 | 说明 |
|------|------|
| **Server** | Web 服务器地址 |
| **Port** | Web 服务器端口 |
| **Log File** | 访问日志文件路径 |
| **Parser Class Name** | 日志解析器类 |

## JSR223 Sampler

使用 JSR223 脚本语言（推荐 Groovy）编写采样器。

| 参数 | 说明 |
|------|------|
| **Language** | 脚本语言（groovy、javascript、beanshell 等） |
| **Script** | 脚本内容 |
| **Parameters** | 传递给脚本的参数 |
| **Cache compiled script** | 缓存编译后的脚本 |

### Groovy 示例

```groovy
// 访问 JMeter 变量
def userId = vars.get("userId")
log.info("Processing user: " + userId)

// 设置采样结果
SampleResult.setResponseOK()
SampleResult.setResponseData("Success", "UTF-8")
```

## JMS Samplers

| **Provider URL** | JMS 提供者 URL |

|------|------|

| 参数 | 说明 |
|------|------|
| **Communication Style** | `Request Only` 或 `Request Response` |

## Flow Control Action

用于条件控制器中暂停或停止目标。

| 操作 | 说明 |
|------|------|
| **Pause** | 暂停指定时间 |
| **Stop** | 停止当前线程 |
| **Stop Now** | 立即停止当前线程 |
| **Go to next iteration** | 跳到下一次迭代 |
