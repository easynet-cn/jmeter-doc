# 09 - 其他组件

## Test Plan

测试计划的根元素。

### 配置

| 选项 | 说明 |
|------|------|
| **Name** | 测试计划名称 |
| **Comments** | 注释 |
| **Functional Test Mode** | 功能测试模式（记录服务器返回数据） |
| **Run Thread Groups consecutively** | 串行运行线程组 |
| **Run tearDown Thread Groups after shutdown** | 关闭后运行 tearDown 线程组 |

---

## Thread Group（标准线程组）

最常用的线程组类型。

### 参数

| 参数 | 说明 |
|------|------|
| **Number of Threads** | 并发线程数 |
| **Ramp-Up Period (seconds)** | 启动全部线程的时间 |
| **Loop Count** | 循环次数（`Infinite` = 无限，`-1` = 无限） |
| **Delay Thread creation until needed** | 延迟线程创建 |
| **Scheduler** | 启用调度器 |
| **Duration (seconds)** | 持续时间 |
| **Startup Delay (seconds)** | 启动延迟 |
| **Specify Thread lifetime** | 线程生命周期 |

### Same user on each iteration

控制在每次迭代时是否模拟同一用户。可配合 Cookie Manager、Cache Manager、Authorization Manager 使用。

---

## Open Model Thread Group

基于开放式工作负载模型的线程组（JMeter 5.5+）。

与标准线程组不同，Open Model Thread Group 使用到达速率模型，更符合真实用户行为。

### 参数

| 参数 | 说明 |
|------|------|
| **Rate** | 到达速率（用户/秒） |
| **Duration** | 持续时间 |
| **Ramp-up** | 增速时间 |
| **Random Seed** | 随机种子 |
| **Rate Limit** | 速率限制 |

---

## setUp Thread Group

在所有测试执行之前运行的线程组，用于初始化操作。

**典型用途**：
- 创建测试数据
- 预热系统
- 初始化环境

---

## tearDown Thread Group

在所有测试执行之后运行的线程组，用于清理操作。

**典型用途**：
- 清理测试数据
- 关闭连接
- 释放资源

---

## Test Fragment

测试片段，不直接执行，通过 Module Controller 或 Include Controller 引用。

**典型用途**：
- 登录模块复用
- 公共请求逻辑封装

---

## WorkBench

工作台区域，用于临时存放测试元素，不参与测试执行。

---

## HTTP(S) Test Script Recorder

HTTP(S) 代理录制器，用于录制浏览器操作生成测试计划。

### 参数

| 参数 | 说明 |
|------|------|
| **Port** | 代理端口（默认 8888） |
| **HTTPS Domains** | HTTPS 域名 |
| **Target Controller** | 目标控制器 |
| **Grouping** | 分组策略 |
| **Capture HTTP Headers** | 是否捕获请求头 |
| **HTTP Sampler settings** | 采样器类型设置 |
| **URL Patterns to Include** | 包含的 URL 模式 |
| **URL Patterns to Exclude** | 排除的 URL 模式 |

### 常用排除模式

```
.*\\.(bmp|css|js|gif|ico|jpe?g|png|swf|woff|woff2)
```

---

## HTTP Mirror Server

HTTP 镜像服务器，将收到的请求原样返回，用于调试。

| 参数 | 说明 |
|------|------|
| **Port** | 镜像服务器端口 |
| **Max Number of Threads** | 最大线程数 |
| **Max Queue Size** | 最大队列大小 |

---

## Property Display

显示 JMeter 属性，用于调试。

---

## Debug Sampler

调试采样器，将 JMeter 变量、属性和系统属性的当前值输出到响应中。

| 参数 | 说明 |
|------|------|
| **JMeter Variables** | 是否显示变量 |
| **JMeter Properties** | 是否显示属性 |
| **System Properties** | 是否显示系统属性 |

---

## SSL Manager

管理 SSL 证书。

- 查看和选择客户端证书
- 在录制 HTTPS 时使用
