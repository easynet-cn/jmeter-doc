# 03 - 监听器

监听器用于收集和展示测试结果。所有监听器保存相同的数据，区别仅在于展示方式。

---

## Sample Result Save Configuration

配置采样结果的保存格式和内容。

| 参数 | 说明 |
|------|------|
| **Filename** | 结果文件路径 |
| **Save As XML / CSV** | 保存格式 |
| **Configure** | 选择保存的字段 |
| **Errors only** | 仅保存错误 |
| **Successes only** | 仅保存成功 |

### 可保存的字段

- timeStamp（时间戳）
- elapsed（耗时）
- label（标签）
- responseCode（响应码）
- responseMessage（响应消息）
- threadName（线程名）
- dataType（数据类型）
- success（是否成功）
- bytes（字节数）
- sentBytes（发送字节数）
- grpThreads（组线程数）
- allThreads（总线程数）
- URL（请求 URL）
- Latency（延迟）
- IdleTime（空闲时间）
- ConnectTime（连接时间）

## View Results Tree

显示每个请求和响应的详细信息，是调试时最常用的监听器。

### 功能

| 视图 | 说明 |
|------|------|
| **Sampler result** | 采样结果摘要 |
| **Request** | 请求详情（请求头、参数等） |
| **Response data** | 响应数据（支持 HTML/XML/JSON 格式化显示） |
| **RegExp Tester** | 内置正则表达式测试器 |

### 配置

| 参数 | 说明 |
|------|------|
| **Filename** | 结果保存文件 |
| **Errors** | 是否记录错误 |
| **Successes** | 是否记录成功 |
| **Configure** | 详细保存配置 |

## Aggregate Report

聚合统计报告，显示每个请求的性能指标。

| 列 | 说明 |
|------|------|
| **Label** | 采样器标签 |
| **# Samples** | 采样数 |
| **Average** | 平均响应时间 |
| **Median** | 中位数（50% 百分位） |
| **90% Line** | 90% 百分位 |
| **95% Line** | 95% 百分位 |
| **99% Line** | 99% 百分位 |
| **Min** | 最小响应时间 |
| **Max** | 最大响应时间 |
| **Error %** | 错误率 |
| **Throughput** | 吞吐量（请求/秒） |
| **Received KB/sec** | 接收速率 |
| **Sent KB/sec** | 发送速率 |

## Graph Results

以折线图形式展示测试数据随时间变化。

显示的指标：
- **Data**（黑色）：当前样本的响应时间
- **Average**（蓝色）：平均响应时间
- **Median**（紫色）：中位数
- **Deviation**（红色）：标准差
- **Throughput**（绿色）：吞吐量

## JSR223 Listener

使用 JSR223 脚本处理采样结果，推荐 Groovy。

### Groovy 示例

```groovy
def responseCode = sampleResult.getResponseCode()
def label = sampleResult.getSampleLabel()
def elapsed = sampleResult.getTime()

log.info("${label}: ${responseCode} in ${elapsed}ms")

if (responseCode != "200") {
    log.warn("Non-200 response for ${label}: ${responseCode}")
}
```
