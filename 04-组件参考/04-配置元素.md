# 04 - 配置元素

配置元素用于设置默认值和变量，由采样器和其他组件使用。配置元素不会发送请求（HTTP(S) Test Script Recorder 除外）。

---

## CSV Data Set Config

从 CSV 文件读取数据，供测试参数化使用。

### 配置参数

| 参数 | 说明 |
|------|------|
| **Filename** | CSV 文件路径 |
| **File Encoding** | 文件编码（默认平台编码） |
| **Variable Names** | 变量名列表（逗号分隔） |
| **Delimiter** | 分隔符（默认 `,`） |
| **Allow Quoted Data** | 是否允许引号数据 |
| **Recycle on EOF** | 到文件末尾是否循环 |
| **Stop Thread on EOF** | 到文件末尾是否停止线程 |
| **Sharing Mode** | 共享模式 |

### 共享模式

| 模式 | 说明 |
|------|------|
| **All threads** | 所有线程共享 |
| **Current thread group** | 线程组内共享 |
| **Current thread** | 每个线程独立 |
| **Identifier** | 按标识符共享 |

### CSV 示例

```csv
username,password,role
alice,pass123,admin
bob,pass456,user
charlie,pass789,user
```

引用方式：`${username}`、`${password}`、`${role}`

## HTTP Request Defaults

设置 HTTP 请求的默认值，避免在每个 HTTP Request 中重复配置。

| 参数 | 说明 |
|------|------|
| **Protocol** | 默认协议 |
| **Server Name or IP** | 默认服务器地址 |
| **Port Number** | 默认端口 |
| **Path** | 默认路径 |
| **Content Encoding** | 默认内容编码 |

---

## HTTP Cookie Manager

管理 HTTP Cookies。

| 参数 | 说明 |
|------|------|
| **Clear cookies each iteration** | 每次迭代清除 Cookie |
| **Cookie Policy** | Cookie 策略（standard、compatibility 等） |
| **Implementation** | 实现方式（HC4CookieHandler 推荐） |

---

## HTTP Header Manager

添加自定义 HTTP 请求头。

常用配置：

| Header | 值 |
|--------|---|
| `User-Agent` | `Mozilla/5.0 ...` |
| `Content-Type` | `application/json` |
| `Accept` | `application/json` |
| `Authorization` | `Bearer <token>` |

---

## HTTP Authorization Manager

管理 HTTP 认证信息。

| 参数 | 说明 |
|------|------|
| **Base URL** | 认证 URL 基础路径 |
| **Username** | 用户名 |
| **Password** | 密码 |
| **Domain** | NTLM 域名 |
| **Realm** | 认证 Realm |
| **Mechanism** | BASIC_DIGEST / KERBEROS |

---

## HTTP Cache Manager

模拟浏览器缓存。

| 参数 | 说明 |
|------|------|
| **Clear cache each iteration** | 每次迭代清除缓存 |
| **Use Thread Group setting** | 使用线程组设置 |
| **Max number of elements** | 最大缓存条目数 |

---

## DNS Cache Manager

管理 DNS 缓存，可模拟每个线程使用不同 IP 地址。

| 参数 | 说明 |
|------|------|
| **Clear cache each iteration** | 每次迭代清除 DNS 缓存 |
| **Use system DNS resolver** | 使用系统 DNS 解析器 |
| **Static Host Table** | 静态主机表 |

---

## JDBC Connection Configuration

配置数据库连接池。

| 参数 | 说明 |
|------|------|
| **Variable Name** | 连接池名（JDBC Request 中引用） |
| **Max Number of Connections** | 最大连接数 |
| **Max Wait (ms)** | 最大等待时间 |
| **Database URL** | JDBC URL |
| **JDBC Driver class** | 驱动类名 |
| **Username / Password** | 数据库认证 |

---

## Keystore Configuration

配置客户端 SSL 证书。

| 参数 | 说明 |
|------|------|
| **Preload** | 是否预加载 |
| **Variable name holding certificate alias** | 证书别名变量 |
| **Alias Start Index / End Index** | 别名索引范围 |

---

## Login Config Element

配置登录信息，供 LDAP 等采样器使用。

| 参数 | 说明 |
|------|------|
| **Username** | 用户名 |
| **Password** | 密码 |

---

## User Defined Variables

定义用户变量，在测试开始时初始化。

```
HOST    = www.example.com
PORT    = 8080
TIMEOUT = 5000
```

引用方式：`${HOST}`

---

## Random Variable

生成随机变量。

| 参数 | 说明 |
|------|------|
| **Variable Name** | 变量名 |
| **Output Format** | 输出格式（如 `0000`） |
| **Minimum Value** | 最小值 |
| **Maximum Value** | 最大值 |
| **Per Thread** | 是否每线程生成 |

---

## Counter

计数器配置元素。

| 参数 | 说明 |
|------|------|
| **Starting value** | 起始值 |
| **Increment** | 步长 |
| **Maximum value** | 最大值 |
| **Number format** | 数字格式 |
| **Reference Name** | 引用名 |
| **Track counter independently** | 是否每线程独立计数 |
