# 08 - 后置处理器

后置处理器在采样器请求之后执行操作，最常用于从响应中提取数据。

---

## Regular Expression Extractor

使用正则表达式从响应中提取值，是最常用的提取器。

### 配置参数

| 参数 | 说明 |
|------|------|
| **Apply to** | Main sample / Sub-samples / JMeter Variable |
| **Field to check** | Body / Headers / URL / Response Code / Response Message |
| **Reference Name** | 变量引用名 |
| **Regular Expression** | 正则表达式 |
| **Template** | 模板（如 `$1$` 表示第一个捕获组） |
| **Match No.** | 匹配编号（0 = 随机） |
| **Default Value** | 默认值 |

### 生成的变量

假设 Reference Name = `myVar`：

| 变量 | 说明 |
|------|------|
| `myVar` | 模板结果 |
| `myVar_g0` | 完整匹配 |
| `myVar_g1` | 第一个捕获组 |
| `myVar_g2` | 第二个捕获组 |
| `myVar_gN` | 第 N 个捕获组 |

### 示例

从 `name="file" value="readme.txt"` 中提取文件名：

- 正则表达式：`name="file" value="([^"]+)"`
- 模板：`$1$`
- 结果：`myVar = readme.txt`

## JSON Extractor

使用 JSONPath 从 JSON 响应中提取值。

| 参数 | 说明 |
|------|------|
| **Names of created variables** | 变量名（分号分隔） |
| **JSON Path Expressions** | JSONPath 表达式（分号分隔） |
| **Default Values** | 默认值（分号分隔） |
| **Match No.** | 匹配编号 |
| **Compute concatenation var** | 是否生成拼接变量 |

### 示例

从响应 `{"data": {"user": {"name": "Alice", "id": 123}}}` 提取：

| 变量名 | JSONPath | 结果 |
|--------|----------|------|
| `userName` | `$.data.user.name` | `Alice` |
| `userId` | `$.data.user.id` | `123` |

## CSS Selector Extractor

使用 CSS 选择器从 HTML 响应中提取值。

| 参数 | 说明 |
|------|------|
| **Reference Name** | 引用名 |
| **CSS Selector Expression** | CSS 选择器 |
| **Attribute** | 要提取的属性（留空获取文本） |
| **Match No.** | 匹配编号 |
| **Default Value** | 默认值 |

### 示例

```html
<div class="price">$99.99</div>
```

- CSS Selector：`div.price`
- Attribute：（留空）
- 结果：`$99.99`

---

## XPath Extractor / XPath2 Extractor

使用 XPath 表达式从 XML/HTML 响应中提取值。

| 参数 | 说明 |
|------|------|
| **Reference Name** | 引用名 |
| **XPath query** | XPath 表达式 |
| **Default Value** | 默认值 |
| **Use Tidy** | 是否使用 Tidy 处理 HTML |
| **Match No.** | 匹配编号 |

---

## Boundary Extractor

使用左右边界提取值（比正则表达式更简单高效）。

| 参数 | 说明 |
|------|------|
| **Reference Name** | 引用名 |
| **Left Boundary** | 左边界 |
| **Right Boundary** | 右边界 |
| **Match No.** | 匹配编号 |
| **Default Value** | 默认值 |

### 示例

从 `<title>My Page</title>` 提取标题：

- 左边界：`<title>`
- 右边界：`</title>`
- 结果：`My Page`

## JSR223 PostProcessor

使用 JSR223 脚本处理响应，推荐 Groovy。

### Groovy 示例

```groovy
def response = prev.getResponseDataAsString()
def json = new groovy.json.JsonSlurper().parseText(response)

// 提取数据
vars.put("userId", json.data.userId.toString())
vars.put("token", json.data.token)

// 条件处理
if (prev.getResponseCode() != "200") {
    log.warn("Non-200 response: ${prev.getResponseCode()}")
}
```

| 参数 | 说明 |
|------|------|
| **Language** | 脚本语言 |
| **Script** | 后置处理脚本 |
| **Cache compiled script** | 缓存编译脚本 |

## Debug PostProcessor

调试后置处理器，将 JMeter 变量和属性写入响应数据中，便于查看。

| 参数 | 说明 |
|------|------|
| **JMeter Variables** | 是否显示变量 |
| **JMeter Properties** | 是否显示属性 |
| **Sampler Properties** | 是否显示采样器属性 |
| **System Properties** | 是否显示系统属性 |
