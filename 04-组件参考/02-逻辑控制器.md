# 02 - 逻辑控制器

逻辑控制器决定采样器的执行顺序和方式。

---

## Simple Controller

最基本的控制器，仅作为容器组织采样器，不改变执行顺序。

**用途**：分组管理请求，便于维护。

---

## Loop Controller

循环执行子元素指定次数。

| 参数 | 说明 |
|------|------|
| **Loop Count** | 循环次数（`-1` 表示无限循环） |

---

## Once Only Controller

确保子元素在每个线程生命周期内仅执行一次。

**典型用途**：登录请求。

---

## Interleave Controller

每次只执行一个子元素，按顺序轮流执行。

```
Interleave Controller
  ├─ Search "A"      ← 第1次迭代执行
  ├─ Search "B"      ← 第2次迭代执行
  └─ Search "C"      ← 第3次迭代执行
```

---

## Random Controller

随机选择并执行一个子元素。

---

## Random Order Controller

随机打乱子元素顺序，但每个都会执行。

---

## Throughput Controller

控制子元素执行的频率（百分比或总数）。

| 参数 | 说明 |
|------|------|
| **Percent Executions** | 按百分比执行 |
| **Total Executions** | 按总执行次数控制 |
| **Per User** | 是否基于每个用户 |

---

## Runtime Controller

控制子元素运行的时间长度。

| 参数 | 说明 |
|------|------|
| **Runtime (seconds)** | 运行时长（秒） |

---

## If Controller

根据条件判断是否执行子元素。

| 参数 | 说明 |
|------|------|
| **Condition** | 判断条件（JavaScript/Groovy/JEXL 表达式） |
| **Interpret Condition as Variable Expression** | 将条件解释为变量表达式 |
| **Evaluate for all children** | 是否对所有子元素都评估条件 |

### 条件表达式示例

```
${JMeterThread.last_sample_ok}              # 上一个采样成功
"${var}" == "expected"                       # 变量等于期望值
${__jexl3(${count} < 5)}                    # JEXL3 表达式
${__groovy(vars.get("count") as int < 5)}   # Groovy 表达式
```

---

## While Controller

当条件为真时循环执行子元素。

| 参数 | 说明 |
|------|------|
| **Condition** | 循环条件（可留空，直到采样失败） |

### 条件示例

```
${__javaScript("${VAR}" != "EOF")}   # 直到变量等于 EOF
${__jexl3(${counter} < 10)}         # 计数器小于 10
last                                # 上次采样不失败
```

---

## Switch Controller

根据变量值选择执行哪个子元素。

| 参数 | 说明 |
|------|------|
| **Switch Value** | 选择值（索引号或名称） |

```
Switch Controller (Switch Value = "pageB")
  ├─ Page A      ← 选择值为 "pageA" 时执行
  ├─ Page B      ← 选择值为 "pageB" 时执行
  └─ Page C      ← 默认
```

---

## ForEach Controller

遍历变量数组。

| 参数 | 说明 |
|------|------|
| **Input variable prefix** | 变量名前缀（如 `user`） |
| **Start index** | 起始索引 |
| **End index** | 结束索引 |
| **Output variable name** | 输出变量名 |
| **Add underscore** | 是否在数字前添加下划线 |

**示例**：
- 输入变量：`user_1=Alice`, `user_2=Bob`, `user_3=Charlie`
- 前缀：`user`，起始：1，结束：3
- 输出变量 `currentUser` 依次为 `Alice` → `Bob` → `Charlie`

---

## Module Controller

引用 Test Fragment 中的模块，实现测试代码复用。

| 参数 | 说明 |
|------|------|
| **Module To Run** | 选择要执行的 Test Fragment 中的模块 |

---

## Include Controller

从外部 JMX 文件加载并执行测试片段。

| 参数 | 说明 |
|------|------|
| **Include Test Plan** | 外部 JMX 文件路径 |

---

## Transaction Controller

将一组请求作为一个事务，可统计总耗时。

| 参数 | 说明 |
|------|------|
| **Generate parent sample** | 生成父级采样结果 |
| **Include duration of timer** | 是否包含定时器耗时 |

---

## Recording Controller

与 HTTP(S) Test Script Recorder 配合使用，录制的请求自动添加到此控制器下。

---

## Critical Section Controller

确保子元素在同一时间只有一个线程执行。

| 参数 | 说明 |
|------|------|
| **Lock Name** | 锁名称（相同名称共享锁） |
