# 07 - 前置处理器

前置处理器在采样器请求之前执行操作，常用于修改请求设置或更新变量。

---

## HTML Link Parser

解析 HTML 响应中的链接，自动提取后续请求的 URL。

| 参数 | 说明 |
|------|------|
| **URL** | 基础 URL |
| **Follow All Anchor Hrefs** | 跟随所有链接 |

---

## HTTP URL Re-writing Modifier

处理 URL 重写的会话 ID。

| 参数 | 说明 |
|------|------|
| **Session Argument Name** | 会话参数名（如 `jsessionid`） |
| **Path Extension** | 是否使用路径扩展 |
| **Do not use equals** | 不使用等号 |
| **Do not use questionmark** | 不使用问号 |
| **Cache Session Id** | 是否缓存会话 ID |

---

## User Parameters

为每个线程设置不同的参数值。

| 参数 | 说明 |
|------|------|
| **Update Once Per Iteration** | 每次迭代更新一次 |
| **Name** | 参数名 |
| **User_1, User_2...** | 每个用户的值 |

### 示例

| 参数名 | User_1 | User_2 | User_3 |
|--------|--------|--------|--------|
| username | alice | bob | charlie |
| password | pass1 | pass2 | pass3 |

---

## BeanShell PreProcessor (已弃用)

使用 BeanShell 脚本处理请求前的逻辑。

> ⚠️ 建议使用 **JSR223 PreProcessor + Groovy**。

---

## JSR223 PreProcessor

使用 JSR223 脚本在请求前执行操作，推荐 Groovy。

### Groovy 示例

```groovy
// 生成随机用户 ID
def userId = UUID.randomUUID().toString()
vars.put("randomUserId", userId)
log.info("Generated user ID: " + userId)

// 动态修改请求路径
def path = sampler.getPath()
sampler.setPath(path + "?traceId=" + userId)
```

| 参数 | 说明 |
|------|------|
| **Language** | 脚本语言 |
| **Script** | 前置处理脚本 |
| **Parameters** | 脚本参数 |
| **Cache compiled script** | 缓存编译脚本 |

## JDBC PreProcessor

在请求前执行数据库操作。

| 参数 | 说明 |
|------|------|
| **Variable Name** | 连接池名 |
| **Query Type** | 查询类型 |

---

## RegEx User Parameters

使用正则表达式为每个线程设置参数。

| 参数 | 说明 |
|------|------|
| **RegEx Param Reference Name** | 正则引用名 |
| **Param Names** | 参数名列表 |

---

## Sample Timeout

设置采样的超时时间。

| 参数 | 说明 |
|------|------|
| **Sample timeout (ms)** | 采样超时（毫秒） |
| **Interrupt timer** | 是否中断定时器 |
