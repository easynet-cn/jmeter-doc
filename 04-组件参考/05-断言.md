# 05 - 断言

断言用于验证服务器返回的响应是否符合预期。

---

## Response Assertion

最常用的断言，检查响应内容。

| 参数 | 说明 |
|------|------|
| **Apply to** | 应用于：Main sample only / Sub-samples only / Main + Sub-samples / JMeter Variable |
| **Field to Test** | 测试字段：Text Response / Response Code / Response Message / Response Headers / Request Headers / URL / Document |
| **Pattern Matching Rules** | 包含 / 匹配 / 等于 / 子字符串 / 不包含 / 不匹配 |
| **Patterns to Test** | 测试模式列表 |

### 模式匹配规则

| 规则 | 说明 |
|------|------|
| **Contains** | 响应包含模式 |
| **Matches** | 响应正则匹配模式 |
| **Equals** | 响应完全等于模式 |
| **Substring** | 响应包含子字符串 |
| **Not** | 反向匹配 |

---

## Duration Assertion

验证响应时间是否在预期范围内。

| 参数 | 说明 |
|------|------|
| **Duration (ms)** | 最大允许响应时间（毫秒） |

---

## Size Assertion

验证响应大小。

| 参数 | 说明 |
|------|------|
| **Size (bytes)** | 期望大小 |
| **Compare Mode** | `=` / `≠` / `>` / `<` / `>=` / `<=` |
| **Size Type** | Full Response / Response Headers / Response Body / Response Code / Response Message |

---

## XML Assertion

验证响应是否为有效 XML。

无特殊参数。

---

## XML Schema Assertion

验证 XML 是否符合指定的 XSD Schema。

| 参数 | 说明 |
|------|------|
| **File Name** | XSD Schema 文件路径 |

---

## XPath Assertion

使用 XPath 表达式验证 XML 响应。

| 参数 | 说明 |
|------|------|
| **Use Tidy** | 是否使用 Tidy 处理 |
| **XML Parsing Options** | 解析选项 |
| **XPath Assertion** | XPath 表达式 |
| **True if nothing matches** | 无匹配时视为成功 |

---

## XPath2 Assertion

使用 XPath 2.0 表达式验证响应。

| 参数 | 说明 |
|------|------|
| **XPath expression** | XPath 2.0 表达式 |
| **Expected value** | 期望值 |
| **Validate against expected value** | 是否与期望值比较 |
| **Ignore Whitespace** | 忽略空白 |
| **Namespace** | 命名空间配置 |

---

## JSON Assertion

验证 JSON 响应。

| 参数 | 说明 |
|------|------|
| **JSON Path** | JSON Path 表达式（如 `$.data.name`） |
| **Expected Value** | 期望值 |
| **Validate against expected value** | 是否与期望值比较 |
| **Expect null** | 是否期望 null |
| **Invert assertion** | 是否反转断言结果 |

---

## JSON JMESPath Assertion

使用 JMESPath 表达式验证 JSON。

| 参数 | 说明 |
|------|------|
| **JMESPath Expression** | JMESPath 表达式 |
| **Expected Value** | 期望值 |

---

## HTML Assertion

验证响应是否为有效 HTML。

| 参数 | 说明 |
|------|------|
| **Errors only** | 仅显示错误 |
| **Warning only** | 仅显示警告 |
| **Error threshold** | 错误阈值 |
| **Warning threshold** | 警告阈值 |
| **Format** | HTML / XHTML / XML |

---

## MD5Hex Assertion

验证响应的 MD5 哈希值。

| 参数 | 说明 |
|------|------|
| **MD5 Hash** | 期望的 MD5 哈希值 |

---

## SMIME Assertion

验证 SMIME 签名邮件。

| 参数 | 说明 |
|------|------|
| **Verify Signature** | 是否验证签名 |
| **Message Position** | 消息位置 |

---

## Compare Assertion

比较两个采样器的结果。

| 参数 | 说明 |
|------|------|
| **Comparison Filters** | 比较过滤规则 |

---

## BeanShell Assertion (已弃用)

使用 BeanShell 脚本验证。

> ⚠️ 建议使用 **JSR223 Assertion + Groovy**。

---

## JSR223 Assertion

使用 JSR223 脚本验证，推荐 Groovy。

### Groovy 示例

```groovy
def response = prev.getResponseDataAsString()
def json = new groovy.json.JsonSlurper().parseText(response)

if (json.status != "success") {
    AssertionResult.setFailure(true)
    AssertionResult.setFailureMessage("Status is not success: " + json.status)
}
```

| 参数 | 说明 |
|------|------|
| **Language** | 脚本语言 |
| **Script** | 断言脚本 |
| **Parameters** | 脚本参数 |
| **Cache compiled script** | 缓存编译脚本 |
